# Анонсы спикеров

Стиль — по референсам: ч/б фото с прошлых мероприятий на фоне, жёлтое свечение, спикер вырезан по контуру на жёлтой «бумажной» подложке, огромное полупрозрачное «СПИКЕР», фамилия на наклонной жёлтой плашке, кнопка-призыв.

- **Figma:** «РЕШЕНО — анонсы спикеров» — https://www.figma.com/design/1FNqlhxDdZgP6twmzb94oU — 2 поста 1080×1350 + 2 сторис 1080×1920, все тексты редактируемые. Фото и фоны в Figma появятся после того, как в настройках окружения будет разрешён домен `mcp.figma.com` (через него Figma принимает загрузку картинок).
- **Готовые PNG:** `post-speaker1.png`, `post-speaker2.png`, `story-speaker1.png`, `story-speaker2.png` — с плейсхолдерами «Имя / Фамилия / Должность / Тема».
- `assets/` — вырезанные ч/б фото спикеров (PNG с прозрачностью), жёлтые подложки по силуэту, ч/б фоны из видео с мероприятий.
- `src/` — исходные фото, `prep.py` (вырезка и фоны), `card.html` + `render.mjs` (рендер PNG).

Новый спикер: положить фото в `src/`, добавить в `prep.py` и `render.mjs`, прогнать оба скрипта.

## Цветной вариант

`*-color.png` — те же карточки, но фото спикера цветное (фон зала остаётся ч/б). Вырезки: `assets/speaker*_cutout_color.png`, делает `src/color.py` (берёт маску из ч/б вырезки). В Figma — секция «Анонсы спикеров — цветное фото» под основной.
