# Маскот — бизон РЕШЕНО

`png/` — бизон без фона (прозрачный PNG), 4 позы:

| Файл | Поза | Куда подходит |
|---|---|---|
| `bizon-dumaet.png` | Задумался, рука у подбородка | Жиза, вопросы, «а вы как думаете?», опросы |
| `bizon-flipchart.png` | У флипчарта с графиком роста | Полезняшки, цифры, разборы |
| `bizon-priglashaet.png` | Приглашающий жест | Продажа, «ждём вас», анонсы |

`primery/` — примеры постов (рендер: `cd content/_kit && node render.mjs mascot.mjs`; положение бизона задаётся полем `mascot` в слайде).

## Роль в контенте

Бизон — «свой» владелец спортивного бизнеса: тоже устал, тоже считает деньги, но знает, где найти решение. Он ведёт смешные и полезные рубрики. Форум, спикеры и продажа остаются серьёзными: бизон там только приглашает.

- **Знакомство (первым делом):** «Как его назовём?» — опрос/конкурс имени в сторис и Telegram. Вовлечение + публика сразу считает маскота «своим».
- **Жиза владельца:** бизон реагирует на знакомые ситуации («А можно заморозить абонемент на лето?»).
- **Бизон считает:** полезняшки у флипчарта: одна цифра, одна формула.
- **Бизон отвечает:** вопросы подписчиков из комментариев и чата → короткий ответ от бизона + «подробно разберём на форуме».
- **Отсчёт:** сторис «До форума N дней» с бизоном в разных позах.
- **Стикеры для Telegram-чата:** набор из поз бизона (нужны ещё 4–6 эмоций: смеётся, в шоке, показывает «класс», держит табличку).
- **На форуме:** ростовая фигура / баннер для фото, бизон на бейджах и навигации.

Для рилсов и стикеров нужно больше поз и эмоций: если у дизайнера есть исходник (3D-модель или генерация), попросить серию в одном стиле.
