## Роль в контенте

Зубр — «свой» владелец спортивного бизнеса: тоже устал, тоже считает деньги, но знает, где найти решение. Он ведёт смешные и полезные рубрики. Форум, спикеры и продажа остаются серьёзными: зубр там только приглашает.

- **Знакомство (первым делом):** «Как его назовём?» — опрос/конкурс имени в сторис и Telegram. Вовлечение + публика сразу считает маскота «своим».
- **Жиза владельца:** зубр реагирует на знакомые ситуации («А можно заморозить абонемент на лето?»).
- **Зубр считает:** полезняшки у флипчарта: одна цифра, одна формула.
- **Зубр отвечает:** вопросы подписчиков из комментариев и чата → короткий ответ от зубра + «подробно разберём на форуме».
- **Отсчёт:** сторис «До форума N дней» с зубром в разных позах.
- **Стикеры для Telegram-чата:** набор из поз зубра (нужны ещё 4–6 эмоций: смеётся, в шоке, показывает «класс», держит табличку).
- **На форуме:** ростовая фигура / баннер для фото, зубр на бейджах и навигации.

Для рилсов и стикеров нужно больше поз и эмоций: если у дизайнера есть исходник (3D-модель или генерация), попросить серию в одном стиле.
