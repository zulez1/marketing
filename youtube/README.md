# YouTube: интро, переход и аутро РЕШЕНО

Стиль — спортивная трансляция (переходы «между иннингами»): через кадр по диагонали пролетают полосы фирменных цветов, под ними — лого РЕШЕНО. Всё 1920×1080, 30 fps, со звуком.

| Файл | Длина | Что это | Куда ставить |
|---|---|---|---|
| `intro-alpha.mov` | 6 с | Интро **с прозрачностью**: полосы закрывают кадр → лого, подпись «Форум владельцев и руководителей спортивного бизнеса», бегущая строка → вторая волна полос уходит и **открывает ваше видео** | На верхнюю дорожку над началом ролика. Видео под ним должно начаться примерно с 5,0 с |
| `intro.mp4` | 6 с | То же на чёрном фоне | Если монтажка не понимает прозрачность — просто в начало ролика |
| `intro-greenscreen.mp4` | 6 с | То же на зелёном фоне | CapCut / мобильные монтажки: наложение + «Хромакей» по зелёному |
| `stinger-alpha.mov` | 1,6 с | **Переход между частями** с прозрачностью: полосы закрывают кадр, вспышка «РЕШЕНО», полосы уходят | Над стыком двух клипов, **склейку делать на 0,8 с** — в этот момент кадр полностью закрыт |
| `stinger.mp4` / `stinger-greenscreen.mp4` | 1,6 с | То же на чёрном / зелёном | CapCut: хромакей по зелёному |
| `outro.mp4` | 20 с | Финальная заставка (конечная заставка YouTube) | В конец ролика |

`.mov` — кодек PNG с альфа-каналом: открывается в Premiere Pro, DaVinci Resolve, Final Cut Pro, After Effects.

## Как настроить конечную заставку YouTube

В YouTube Studio → Редактор → Конечная заставка (последние 20 с ролика):
- **Подписка** (круглый элемент канала) — на пунктирный круг слева внизу
- **Видео / плейлист** — на две рамки справа: «Смотрите далее» и «Ещё видео»

Рамки и круг в самом ролике — только разметка, их закрывают элементы YouTube.

## Звук

Свой, в фирменной тональности (ля минор): «вжух» на каждой волне полос (идёт слева направо вместе с ними), удар и аккорд на появлении лого, перезвон на блике по надписи. В аутро — спокойная подложка на 20 с, в конце плавно затихает. Если нужен ролик без звука — просто выключите звуковую дорожку клипа.

## Исходники

`src/yt.html` — анимация (3 сцены), `src/cap.mjs` — рендер кадров, `src/yt_audio.py` — звук. Поменять текст/дату → перерендерить:

```bash
cd /home/user/marketing && python3 -m http.server 8767 --bind 127.0.0.1 &
cd youtube/src && node cap.mjs intro frames fr-intro   # stinger / outro аналогично
python3 yt_audio.py
```
