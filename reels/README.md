## Подписи

**Полный зал**
> Так выглядит зал, когда в нём собираются владельцы спортивного бизнеса. Не просто послушать — приехать решить. Подробности — по ссылке в профиле.

**Как это выглядит**
> Регистрация, кофе, полный зал, разборы, вопросы из зала и знакомства, ради которых стоит ехать. Вот как это выглядит изнутри.

**Сцена**
> Минимум сцены. Максимум разбора. На сцене — только те, кому есть что показать: цифры, ошибки, результаты.

**Hot Seat**
> Здесь задают вопросы, которые обычно не задают публично. И получают ответы.

## Как пересобрать / сделать новый

Исходники лежат на Яндекс Диске («Видео СММ»), в репозиторий не кладутся. Рилс описывается JSON-сценарием в `src/specs/` (какой файл, с какой секунды, сколько долей, замедление, наезд, где вспышка, какие титры) и собирается одной командой:

```bash
cd reels/src && python3 build.py specs/reel1-polnyy-zal.json
```

`cut.py` — нарезка и цвет, `overlay.html` — титры и концовка, `music.py` — трек и удары под склейки, `build.py` — сборка.
