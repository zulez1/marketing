# Рилсы из «Видео СММ» — атмосфера форума

1080×1920, 30 fps, 17–20 с, без речи: монтаж в долю (120 BPM), у каждого рилса свой трек, замедления (исходники сняты в 60 fps), наезды и отъезды камеры, вспышки на акцентных склейках, фирменные титры и концовка с полосами РЕШЕНО. Исходники — iPhone 4K HDR, переведены в обычный цвет (SDR, BT.709) с цветокоррекцией; файлы помечены как BT.709, поэтому фирменный жёлтый #F0B90B не уходит в оранжевый на телефонах. Кадры с едой не используются.

## Версии без музыки — под трендовый звук

`bez-muzyki/*-bez-muzyki.mp4` — тот же монтаж, но вместо трека только «вжухи» на склейках и удары на акцентах. Трендовый звук добавляется в самом приложении — так Instagram засчитывает использование тренда, и не будет проблем с авторскими правами (вшитая в файл чужая музыка может быть заглушена).

**Instagram:** новый Reels → выбрать видео → «Аудио» (значок ноты) → вкладка «Популярное» / трек со стрелкой ↗ (это трендовые) → сдвинуть фрагмент так, чтобы удар трека совпал с первой склейкой (≈2 с у «Полного зала», 1 с у остальных) → «Громкость» → оригинальный звук 20–40 %, трек 100 %.
**VK Клипы:** «Музыка» → выбрать трек из каталога VK → так же подогнать начало.

Монтаж нарезан в 120 BPM: лучше всего ложатся треки 120 или 60/240 BPM; у треков 115–125 BPM склейки тоже будут попадать почти в долю.

Бизнес-аккаунтам Instagram доступна не вся музыка — только разрешённая для коммерческого использования. Если нужного трека нет, переключите профиль на «Автор» или возьмите трек из доступных.

## Подписи

**Полный зал**
> Так выглядит зал, когда в нём собираются владельцы спортивного бизнеса. Не просто послушать — приехать решить. Подробности — по ссылке в профиле.

**Как это выглядит**
> Регистрация, полный зал, разборы, вопросы из зала и знакомства, ради которых стоит ехать. Вот как это выглядит изнутри.

**Сцена**
> Минимум сцены. Максимум разбора. На сцене — только те, кому есть что показать: цифры, ошибки, результаты.

**Hot Seat**
> Здесь задают вопросы, которые обычно не задают публично. И получают ответы.

## Как пересобрать / сделать новый

Исходники лежат на Яндекс Диске («Видео СММ»), в репозиторий не кладутся. Рилс описывается JSON-сценарием в `src/specs/` (какой файл, с какой секунды, сколько долей, замедление, наезд, где вспышка, какие титры) и собирается одной командой:

```bash
cd reels/src && python3 build.py specs/reel1-polnyy-zal.json
```

`cut.py` — нарезка и цвет, `overlay.html` — титры и концовка, `music.py` — трек (стиль задаётся полем `style`: house / trap / epic / tension) и удары под склейки, `build.py` — сборка.
